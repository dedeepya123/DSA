# Directed Cycle Detection using BFS (Kahn's Algorithm)

## 1. Objective

Given a directed graph, determine whether the graph contains a cycle.

We can solve this using **Kahn's Algorithm**, which is also used for topological sorting.

The key idea is to repeatedly process vertices that have an indegree of zero.

If we cannot process all vertices, the graph contains a cycle.

## 2. Graph Representation

We use an adjacency list to represent the directed graph.

For every directed edge `(u, v)`:

- Add `v` to `adj[u]`.
- Increment `indegree[v]` by 1.

**Indegree:** The number of incoming edges to a vertex.

A vertex with indegree zero has no incoming dependencies and can be processed immediately.

## 3. Intuition

Think of a directed graph as a dependency graph.

An edge `u → v` means that `v` depends on `u`.

We can process a vertex only when all its incoming dependencies have been satisfied.

Therefore:

1. Start with all vertices having indegree zero.
2. Process one vertex.
3. Remove its outgoing edges conceptually by decrementing the indegree of its outgoing neighbors.
4. If a neighbor's indegree becomes zero, all its dependencies have been satisfied. Add it to the queue.
5. Continue until the queue becomes empty.

### Why does this detect a cycle?

Consider a directed cycle:

`1 → 2 → 3 → 1`

Every vertex in the cycle has at least one incoming edge from another vertex in the same cycle.

Therefore, none of these vertices can initially have indegree zero.

Since we cannot process any vertex in the cycle, their incoming dependencies can never be fully removed.

Eventually, the queue becomes empty while some vertices remain unprocessed.

Hence:

- If `processed_count == V`, no cycle exists.
- If `processed_count < V`, a cycle exists.

Note: Some unprocessed vertices may be downstream of a cycle rather than part of the cycle themselves.

## 4. Algorithm

1. Build the adjacency list and calculate indegrees.
   - For every edge `(u, v)`, add `v` to `adj[u]`.
   - Increment `indegree[v]`.

2. Initialize a queue.
   - Add all vertices with indegree zero.

3. Process the queue.
   - While the queue is not empty:
     - Remove a vertex.
     - Increment `processed_count`.
     - For every outgoing neighbor:
       - Decrement its indegree.
       - If its indegree becomes zero, add it to the queue.

4. Check the processed count.
   - If `processed_count < V`, return `True`.
   - Otherwise, return `False`.

## 5. Python Implementation

```python
from collections import defaultdict, deque

def has_cycle(n, edges):
    adj = defaultdict(list)
    indegree = [0] * n

    # Build adjacency list and calculate indegree
    for u, v in edges:
        adj[u].append(v)
        indegree[v] += 1

    # Add all vertices with indegree 0
    queue = deque()

    for node in range(n):
        if indegree[node] == 0:
            queue.append(node)

    processed_count = 0

    while queue:
        node = queue.popleft()
        processed_count += 1

        for nei in adj[node]:
            indegree[nei] -= 1

            if indegree[nei] == 0:
                queue.append(nei)

    return processed_count < n
```

## 6. Dry Run

Consider the directed graph:

```text
0 → 1 → 2
    ↑
    3
```

Edges:

```python
edges = [(0, 1), (1, 2), (3, 1)]
n = 4
```

### Initial indegrees

| Vertex | Indegree |
|---|---:|
| 0 | 0 |
| 1 | 2 |
| 2 | 1 |
| 3 | 0 |

Initially:

```text
Queue = [0, 3]
processed_count = 0
```

### Processing

| Processed vertex | Indegree changes | Queue |
|---|---|---|
| 0 | indegree[1]: 2 → 1 | [3] |
| 3 | indegree[1]: 1 → 0 | [1] |
| 1 | indegree[2]: 1 → 0 | [2] |
| 2 | No outgoing neighbors | [] |

Final result:

```text
processed_count = 4
V = 4
```

Since `processed_count == V`, no cycle exists.

## 7. Complexity Analysis

Let:

- `V` = number of vertices
- `E` = number of directed edges

**Time Complexity: O(V + E)**

- Building the adjacency list and indegree array takes O(V + E).
- Initializing the queue takes O(V).
- Every vertex is processed at most once.
- Every edge is examined once when processing its source vertex.

**Auxiliary Space: O(V)**

- Indegree array: O(V).
- Queue: O(V).

**Total Space: O(V + E)** including the adjacency list.

## 8. Edge Cases

1. Empty graph (`n = 0`): No cycle.
2. Single isolated vertex: No cycle.
3. Directed acyclic graph (DAG): All vertices can be processed.
4. Directed cycle: Some vertices remain unprocessed.
5. Self-loop (`u → u`): Cycle exists.
6. Disconnected graph: The algorithm handles all components because all zero-indegree vertices are added initially.
7. A cycle with downstream vertices: Both cycle vertices and potentially their downstream dependents remain unprocessed.

## 9. BFS vs DFS for Directed Cycle Detection

| Aspect | DFS | BFS (Kahn's Algorithm) |
|---|---|---|
| Main idea | Detect a back edge | Process zero-indegree vertices |
| Data structure | Recursion stack / explicit stack | Queue |
| Cycle condition | Neighbor is in active DFS path (state 1) | Processed count less than V |
| Extra tracking | Three-state array | Indegree array |
| Connection | DFS traversal | Topological sorting |

Both approaches take O(V + E) time.

## 10. Quick Recall

- Directed graph → calculate indegree.
- Indegree zero → no incoming dependencies.
- Queue → vertices ready to process.
- Processing a vertex → decrement indegree of outgoing neighbors.
- Indegree becomes zero → enqueue neighbor.
- `processed_count < V` → cycle exists.
- `processed_count == V` → no cycle.
